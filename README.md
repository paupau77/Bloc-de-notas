## ✨ Características

- 🧠 **Guardado automático** en localStorage  
- 🆕 **Crear, renombrar, eliminar y buscar** notas  
- 📤 **Exportar** y 📥 **importar** notas en formato `.txt`  
- 🔢 **Contador** de palabras y caracteres  
- ⌨️ **Atajo de teclado:** `Ctrl + S` para guardar  
- 🌙☀️ **Modo oscuro / claro**  
- 💻 **Diseño responsive** con animaciones suaves  
- 🔒 Todo se guarda **localmente**, sin servidores ni cuentas
